# assets/

Art, sound and type for every screen. Everything here is listed in
`/CREDITS.md`; the current files are placeholders generated by
`tools/asset_gen/` (CC0). Regenerate after changing `data/feel/palette.json`
or `data/feel/sprite_manifest.json`:

```sh
python3 tools/asset_gen/gen_sprites.py   # sprites, effects, interface, icons (needs Pillow)
python3 tools/asset_gen/gen_enemies.py   # enemy faction sprites in enemies/ (needs Pillow)
python3 tools/asset_gen/gen_font.py      # Mech Pixel font (needs Pillow)
python3 tools/asset_gen/gen_sfx.py       # sound effects and music loop
python3 tools/asset_gen/gen_music.py     # context music in music/: menu, battle, boss, readout, stings
godot --headless --import --path .       # reimport
godot --headless --path . -s res://ui/common/build_theme.gd   # rebuild the theme
```

| Folder | What |
|---|---|
| `sprites/units/<unit>/` | Unit sheets, one per tier (enemies) or per part, variant and tier (allies) |
| `enemies/<faction>/` | Enemy faction sheets, `<unit>_<tier>.png`, one per unit type and tier (P4) |
| `sprites/effects/` | Effect sheets, one row of frames each (listed under `effects` in the manifest) |
| `sprites/particles/` | Small white textures for particle systems to tint |
| `ui/` | 9-slice boxes for the theme (12x12 art stored at 2x), checkbox, slider, arrow |
| `ui/icons/` | Status icons (12x12) and popup icons |
| `fonts/` | Mech Pixel, a 5x7 bitmap font. Line height 10 px: draw at 10, 20 or 30 |
| `audio/sfx/`, `audio/music/` | Sounds; which plays when is set in `data/feel/audio.json` |
| `audio/default_bus_layout.tres` | Buses: Master, Music, Effects, Interface |

## Pixel-art rules

- Canvas textures default to nearest filtering (`project.godot`); textures
  import without mipmaps. The window stretches in `canvas_items` mode with
  integer scaling, and 2D transforms snap to whole pixels.
- Draw sprites at whole-number scales only: units at `display_scale` (3), the
  interface at 2x (the font at 20 px, boxes stored at 2x).
- Colors come from `data/feel/palette.json`. Status is never color alone: each
  status icon has its own shape, popups carry a sign and an icon, and low
  health adds stripes to the bar.

## Sprite manifest: `data/feel/sprite_manifest.json`

P2 (battle renders) and P4 (enemy factions) add units here; a new unit then
needs only art and a manifest entry. `ui/common/sprite_manifest.gd` reads it
and `ui/common/unit_sprite.gd` draws a unit from it.

### Top level

| Key | Meaning |
|---|---|
| `version` | Format version, 1 |
| `frame_size` | `[w, h]` of one frame in every sheet, 32x32 |
| `display_scale` | Whole-number scale units are drawn at (3 = 96 px on screen) |
| `tiers` | `["beginner", "medium", "advanced"]`, weakest first |
| `animations` | The sheet layout: name -> `{row, frames, fps, loop}` |
| `key_colors` | Palette names (from `palette.json`) of the colors ally parts are drawn in, by group: `primary` (3, dark to light), `secondary` (3), `glow` (1) |
| `ally_palettes` | Name -> `{primary: [3 hex], secondary: [3 hex], glow: [1 hex]}`, the colors that replace the key colors |
| `units` | Unit id -> unit entry (below) |
| `effects` | Effect id -> `{sheet, frame_size, frames, fps}`, one row of frames |

### Sheet layout

A sheet is a grid of `frame_size` cells: one row per animation (`row`), frames
left to right from column 0. Unused cells stay transparent. The default layout:

| Row | Animation | Frames | fps | Loops | Used for |
|---|---|---|---|---|---|
| 0 | `idle` | 4 | 6 | yes | Standing |
| 1 | `windup` | 3 | 12 | no | Before an attack or skill |
| 2 | `attack` | 4 | 12 | no | The strike; frame 0-1 carry the flash |
| 3 | `hit` | 3 | 12 | no | Taking damage (the engine adds a white flash) |
| 4 | `guard` | 2 | 4 | yes | Guarding |
| 5 | `heal` | 4 | 10 | no | Healing or being healed |
| 6 | `down` | 4 | 8 | no | Knocked out; ends on the last frame |

windup + attack at these rates is about 580 ms, inside the 300-600 ms attack
rule. A unit may carry its own `frame_size` or `animations` to override these.
Units face right (allies) or left (enemies) as drawn; `facing` records it.

### Enemy entry

```json
"enemy_drone": {
  "kind": "enemy",
  "display_name": "Hunter drone",
  "faction": "rival_ai",
  "facing": "left",
  "sheets": {"beginner": "res://...drone_beginner.png", "medium": "...", "advanced": "..."}
}
```

One full sheet per tier, colored as drawn (each enemy type has its own look and
a faction color). Tiers read as the same unit getting stronger: same
silhouette, more armor, bigger weapon, brighter effects. P4 adds one entry per
unit type; `faction` is one of the P4 factions (`human_resistance`,
`enhanced_humans`, `rival_ai`, `aliens`).

Which sheet draws a fight enemy: each enemy in `data/combat/enemy_tables.json`
names its manifest unit and tier (`sprite`, `tier`).
`SpriteManifest.for_enemy("resistance_soldier_medium#2")` returns
`{"unit": "resistance_soldier", "tier": "medium"}` for a combatant id or an
enemy id. The faction colors and the drawing code for these units are in
`tools/asset_gen/gen_enemies.py`; `ui/dev/enemy_lineup.tscn` shows them all.

### Ally entry

```json
"ally_frame": {
  "kind": "ally",
  "display_name": "Frame bot",
  "facing": "right",
  "layers": ["legs", "body", "head", "arm"],
  "parts": {
    "legs": {
      "biped":  {"beginner": "res://...legs_biped_beginner.png", "medium": "...", "advanced": "..."},
      "treads": {"beginner": "...", "medium": "...", "advanced": "..."}
    },
    "body": {...}, "head": {...}, "arm": {...}
  },
  "palettes": ["teal", "amber", "violet", "steel", "lime", "rose"]
}
```

- `layers` is the draw order, back to front. Every part sheet uses the same
  layout and frame size, and its frames line up with the other parts' frames,
  so stacking one sheet per layer gives the whole bot.
- `parts.<layer>.<variant>.<tier>` is one sheet. Allies get more variants than
  enemies; add a variant by adding a key with its three tier sheets.
- Part sheets are drawn in the key colors (pure reds = primary ramp, pure
  greens = secondary ramp, pure blue = glow) plus fixed outline and metal
  colors. `ui/common/palette_swap.gdshader` replaces key colors with the bot's
  palette, so one set of sheets gives every color scheme.
- `palettes` lists the `ally_palettes` this unit may use.
- A drafted bot's look is `SpriteManifest.ally_look(unit_id, seed)`: one
  variant per layer and one palette, the same every time for the same seed
  (use the bot's id or draft seed).
- Which tier a bot shows is the tier-rule switch (TODO(decision:
  tier-rule), read by `ui/fight/battle_tier_rule.gd`); the manifest only
  says what each tier looks like.
- Battle art (extra ally parts, the fallback enemy, skill effects, intent
  icons, tier plates, skill sounds) lives in `assets/fight/`, generated by
  `tools/asset_gen/gen_battle.py`.

### Drawing a unit

```gdscript
var sprite := UnitSprite.new()
sprite.setup("ally_frame", "medium", SpriteManifest.ally_look("ally_frame", bot_seed))
add_child(sprite)
sprite.play("attack")            # follows the animation speed setting
await sprite.animation_finished
sprite.set_flash(1.0)            # hit flash, tween back to 0
```

The demo at `ui/common/demo/sprite_demo.tscn` shows both sample units in all
three tiers and every animation.
