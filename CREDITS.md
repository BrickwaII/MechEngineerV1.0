# Credits

Every asset in `assets/` is listed here with its source and license.
`tests/ui/common/pixel_pipeline_test.gd` fails if a file in `assets/` matches
no path below, so a new asset cannot land without a credit line.

## Current assets: generated for this project (CC0)

The plan was CC0 packs from Kenney (kenney.nl) and OpenGameArt. This build
environment cannot reach either site (and Google Fonts is blocked too), so every
asset below is placeholder art, sound and type **generated by scripts in
`tools/asset_gen/`** from the palette and manifest in `data/feel/`. They are
our own work, dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
(see `assets/LICENSE.md`). Each one can be swapped for a pack asset later by
replacing the file (same size and layout) and updating its row here.
